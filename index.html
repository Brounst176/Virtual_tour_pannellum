📝 Comment ajouter une nouvelle visite

Pour ajouter une nouvelle visite virtuelle, modifiez la configuration dans le code JavaScript :

const tours = [ { id: "heig-vd", title: "HEIG-VD", description: "Campus de l'école", image: "/images/heig-cover.jpg", scenes: 5, badge: "Nouveau" }, // Ajoutez vos visites ici... ];

Fichiers nécessaires :

  • config-{id}.json : Configuration de la visite
  • Image de couverture (format carré recommandé)

💡 Astuce : Utilisez l'éditeur de configuration pour créer votre fichier JSON facilement !
